# Регрессии workspace snapshot и OAuth

Сохранить незалитые unit-тесты из основного workspace, перенести на текущий main
и выполнить закреплённым JDK/Gradle без изменения runtime.

Покрыть поиск корня проекта из вложенного каталога, приоритет команд проверки,
невалидный или отсутствующий cwd, ограничение размера manifest, настоящий Git
со сменой branch/detached HEAD. Проверить OAuth code exchange с PKCE, URL encoding,
TTL fallback, однократное использование state и исчезнувшую конфигурацию.

Результат: два целевых JUnit-класса прошли; внешний OAuth не вызывается.
Тестовый HTTP-сервер использует loopback и завершается в finally.
API, схема БД и production-поведение не изменяются.
