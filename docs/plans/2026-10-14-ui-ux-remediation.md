# Доработки UI/UX 2026-10-14

UX-13. `/help` показывает короткий старт, `/help all` — полный registry;
существующие aliases продолжают работать. Неизвестные аргументы объясняют два
варианта справки. В коротком списке нет незарегистрированных команд.

Справка строится локально в CLI и Telegram-боте. Она не меняет web UI, SSO,
HTTP API, БД, provider configuration или Base pins. Поставка не зависит от
Base PR #206; общая межпродуктовая UI-приёмка выполняется отдельно.

Изменённые CLI/registry/handler тесты и путь через `BotMessageProcessor` в тестовый
`TelegramClient` проходят без внешней отправки. Hosted CI исходника
`2a670fe3e1cb8794397bfae4f796f3167910c6af` прошёл все пять jobs: backend tests,
slow PostgreSQL integration, bot/CLI tests, coverage ratchet, bootJar и
документационные проверки. Последующая правка README и этого документа не меняет
исходники или настройки сборки. CI новой ревизии учитывается отдельно.

Исторические локальные Gradle-прогоны имели ограничения DNS/асинхронных тестов
в Linux и платформенных путей/shell в Windows. Они не объявляются зелёными;
успешная полная проверка выполнена hosted CI на Linux.

Merge проверенного исходника и установка runtime — отдельные действия.
Перезапуск сервисов или обновление установленного Java-образа не выполняются
самим слиянием PR.
